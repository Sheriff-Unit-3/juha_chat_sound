# juha_chat_sound
A mod for [Luanti](https://www.luanti.org/) that plays a sound every time a player sends a message in chat.

## Features
- Plays a sound whenever any message is sent in chat
- Lightweight and with no external dependencies

## Installation
1. Copy the `juha_chat_sound` folder into your game's `mods/` directory.
2. Enable the mod in the game configuration or in `game.conf`.
